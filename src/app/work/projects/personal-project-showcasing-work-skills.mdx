## Overview

Development of the personal university project using skills gained from work experience and new learnings.

A bilingual (English and Armenian) university website built on Drupal 11.

Drupal 11 · Group · Paragraphs · Views · Search API · Content Moderation · Twig and Single Directory Components · Tailwind CSS · Alpine.js · GitLab CI · Pantheon
